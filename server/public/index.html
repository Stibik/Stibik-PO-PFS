Готово

Введите токены API для каждого магазина (получаются в кабинете продавца Kaspi, раздел API). Без токена синхронизация для этого магазина работать не будет.

Нумерация заказов

Внутренний короткий номер заказа (тот, что видят сотрудники и печатается на этикетках) — не код Kaspi. У каждого магазина свой отдельный счётчик, чтобы номера SA и PFS не путались между собой. Можно продолжить счёт с того места, где остановились в PRODIX или на бумаге, вместо того чтобы начинать с 1.

Автоматические копии (откат)
Программа сама сохраняет копию базы перед массовой загрузкой справочника и переносом данных. Хранятся последние 20.
Восстановить базу из копии
Заменяет все данные на те, что в файле: заказы, номера, товары, зарплату, пользователей. Нужно после переезда на постоянный диск. Текущая база сохранится рядом на всякий случай.

Привязать фотографии к товарам

У этих файлов имя не совпало с артикулом — обычное дело для фото с телефона. Найдите товар по названию и нажмите на него. Файлы уже загружены, заново выбирать не нужно.

Перенос из старой системы

Из вашего Excel переносятся три вещи: номера заказов (привязка по коду Kaspi), сотрудники и зарплата — что уже выплачено и что осталось должны. Сначала посмотрите предпросмотр, ничего не изменится, пока не нажмёте «Залить».

Тестовые доступы

Заведены швея и трое забивщиков. Пароли простые — это тестовые учётки, после проверки их можно отключить кнопкой «Отключить» в списке пользователей.

Выдать со склада

Выберите заказ — изделие уйдёт со склада, а заказ закроется как «Списано со склада». Зарплата за него не начисляется: работа уже оплачена.
